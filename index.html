Use it in your browser

Install the Shiralong extension for Chrome, Edge or Brave. It adds a lyrics panel next to the Spotify web player — nothing to sign up for.

  1. Install the extension from the Chrome Web Store.
  2. In Chrome, open open.spotify.com and log in to Spotify as usual.
  3. Play a song. The lyrics appear on the right; click the Shiralong icon to hide or show them.

Looking for songs? Check out the Shiralong playlist — all our songs, with lyrics and translations ready to go.

Works with Spotify in the Chrome browser on a computer, not the Spotify app or phones. Songs are added to the library over time; if one is missing, you'll see a note in the panel.
