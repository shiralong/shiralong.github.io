Automatic lyrics

New songs are looked up on LRCLIB (a free lyrics database with timings) and translated with the service you pick. Everything is stored only in this browser.

Translate a whole playlist

Looks up and translates every song in a playlist once, using the service in Settings, and stores the results in this browser. When it finishes, download songs.json and commit it to the repo so everyone gets the lyrics with no API key. Songs already done are skipped, so you can stop and resume.

    Sync lyrics

    Usually you won't need this page: new songs are fetched and translated automatically. Use it when a song isn't found, or to fix a translation or timing. Fill the boxes (or press the buttons), then either use the fetched timings or tap Now / Space at the start of each line.
